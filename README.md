## Features

* **Feature 1:** High-impact technical detail written as a short bullet point.
* **Feature 2:** Live hot-reload pipeline updating layout previews seamlessly.
* **Feature 3:** Robust relational data architecture ensuring tenant isolation.

## 🛠️ The Tech Stack

| Layer | Technology | Purpose |
| :--- | :--- | :--- |
| **Frontend** | Next.js (App Router), Tailwind CSS | User interface, state management, layouts |
| **Backend Engine** | Python (FastAPI), Manim | Compute engine, heavy rendering workflows |
| **Database** | Neon Postgres | Scalable relational data storage |
| **Auth / Gateway**| Clerk, Svix Webhooks | Secure authentication and account sync |
