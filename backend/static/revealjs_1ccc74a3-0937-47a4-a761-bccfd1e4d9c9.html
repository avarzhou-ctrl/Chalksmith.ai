Decoding [object Object]

Understanding JavaScript's most common output mystery.

What is [object Object]?

  • It is the default string representation of a JavaScript Object.
  • It appears when an object is forced into a string context (Coercion).
  • It tells you: "This is an object of the type Object."

How does it happen?

When JavaScript expects a string but receives an object, it calls the internal .toString() method.


const user = { name: "Alice" };

// Implicit Coercion
console.log("User: " + user); 
// Output: "User: [object Object]"

// Explicit Coercion
String(user); 
// Output: "[object Object]"

The Conversion Process

Common Culprits

1. String Concatenation


"Data: " + obj;

2. Template Literals


`Display: ${obj}`;

3. Alerting an Object


alert({ key: "value" }); // [object Object]

Solution 1: JSON Stringify

To see the actual content of the object, convert it to a JSON string.


const data = { id: 101, status: "active" };

console.log("Data: " + JSON.stringify(data));
// Output: Data: {"id":101,"status":"active"}

Note: JSON.stringify can also take arguments for pretty-printing.

Solution 2: Comma separation

Modern browsers handle objects natively if passed as a separate argument to console.log.


const user = { name: "Bob" };

// WRONG: Concatenation forces string
console.log("User: " + user); 

// RIGHT: Comma keeps the object interactive
console.log("User:", user);

Advanced: Overriding

You can define your own toString() method to change this behavior.


const car = {
    brand: "Tesla",
    toString() {
        return `Car: ${this.brand}`;
    }
};

console.log("" + car); // "Car: Tesla"

Glossary

Coercion
The automatic or implicit conversion of values from one data type to another.
Prototype
A mechanism by which JavaScript objects inherit features from one another.
JSON
JavaScript Object Notation - a standard text-based format for representing structured data.

Key Takeaways

  1. [object Object] is the result of Object.prototype.toString().
  2. It happens during Type Coercion (String + Object).
  3. Use JSON.stringify() to inspect data in strings.
  4. Use commas in console.log() for interactive debugging.
